# Booking Bot — онлайн-запись в Telegram

Готовый бот записи для барбершопов, салонов, мастеров маникюра, массажистов, репетиторов, автосервисов.
Тот же стек, что у PlateAI: Vercel + Upstash Redis, **ноль зависимостей**, хостинг бесплатный.

## Что умеет

**Клиент**
- Услуга → день → время за 3 нажатия (показываются только реально свободные слоты)
- Телефон одной кнопкой «Отправить мой номер», запоминается на следующие записи
- «Мои записи» с отменой (запрет отмены позже чем за N часов)
- Напоминание накануне с кнопкой «Не смогу прийти»

**Владелец** (ID в `ADMIN_IDS`)
- Мгновенное уведомление о новой записи/отмене с телефоном и ссылкой на клиента
- `/today`, `/tomorrow`, `/week` — расписание и выручка
- `/off 05.10`, `/on 05.10` — закрыть/открыть день
- `/broadcast текст` — рассылка всем, кто когда-либо писал боту
- Вечерняя сводка на завтра

**Надёжность:** слот бронируется атомарно (`HSETNX`), двойная запись невозможна; дубли апдейтов Telegram отсекаются.

## Запуск под нового клиента (~15 минут)

1. Создать бота у [@BotFather](https://t.me/BotFather) → получить токен. Поставить аватар и описание в стиле бизнеса.
2. Поправить `config.js`: название, адрес, часы работы, услуги, цены, часовой пояс.
3. Залить на Vercel (Root Directory = `booking-bot`), добавить Upstash Redis из Marketplace.
4. Переменные окружения:

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | любая длинная случайная строка |
| `ADMIN_IDS` | Telegram ID владельца/админов через запятую (узнать: @userinfobot) |
| `CRON_SECRET` | любая случайная строка — защищает `/api/cron` |
| `UPSTASH_REDIS_REST_URL` / `_TOKEN` | подставляются Vercel автоматически |
| `REDIS_PREFIX` | *(опц.)* уникальный префикс, если несколько клиентов в одной базе |

5. Открыть `https://ПРОЕКТ.vercel.app/api/setup?secret=TELEGRAM_WEBHOOK_SECRET` — в ответе всё должно быть `true`.
6. Написать боту `/start` и сделать тестовую запись.

Напоминания уходят раз в день в 15:00 UTC (18:00 МСК) — время меняется в `vercel.json`.

## Структура

```
config.js        — всё, что меняется под клиента
api/webhook.js   — бот (клиентские сценарии + админка)
api/cron.js      — напоминания и вечерняя сводка
api/setup.js     — подключение webhook и меню команд
lib/core.js      — Telegram, Redis, время
lib/bookings.js  — слоты и записи
```
